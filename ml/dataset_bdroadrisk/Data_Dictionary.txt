Dataset Overview: 
The BDRoadRisk dataset contains 10 million synthetic GPS-based traffic event records simulating road conditions on the urban road networks of Dhaka and Chittagong, Bangladesh. Each record includes 23 features and a target class. The target class has 3 attributes which are No_accident, Minor and Major. The dataset can be used to measure how severe a recorded accident was, with post-incident severity classification tasks. The No_Accident class is included to represent near-miss and non-collision events, whereas Minor class indicates minor collusion and injury and Major class indicates fatal and serious injuries.

Dataset Composition: 
- Total Records: 10 million
- Total Features: 23 
- Target Class Labels: No_accident, Minor and Major.
- Class Distribution: No_accident 74.41%, Minor 17.30%, and Major 8.28%.

The dataset consists of Pre-Accident features describing environmental, road, vehicle, and driver conditions before an accident, and Post-Accident features representing driving behavior and incident-related factors after the accident occurrence.
